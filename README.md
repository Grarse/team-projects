## Даты изменений в каталоге

Карточки показывают дату и время последнего коммита, затронувшего папку проекта, в часовом поясе UTC+5. Порядок — от последних изменений к более ранним; для одинакового времени используется стабильный порядок по пути проекта.

В HTML сохранены исходные даты и готовый порядок. `project-updates.js` автоматически уточняет даты по публичной истории GitHub, сортирует карточки и кеширует результат на 10 минут. При недоступности GitHub API или локального хранилища каталог сохраняет работоспособность и исходные даты. Токены и авторизация посетителю не нужны.
