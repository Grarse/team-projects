# Call Spread на металлы

Публичная страница: https://grarse.github.io/team-projects/pcc-metals-call-spread-calculator/

`index.html` — самостоятельная страница с встроенными стилями, скриптами и SVG-графиком. Сборка, сторонние библиотеки и локальный сервер не нужны. Публикуется существующим GitHub Pages из корня `main`.

## Условия и расчёты

- ISIN: MU0803E00165.
- Номинал: 1 000 USD. Цена покупки по паспорту: 10.83% номинала.
- Активы: GLD, SLV, SPPP, SCOP; равные веса.
- Начальная фиксация: 2026-10-07. Финальная оценка: 2027-10-06. Плановая выплата: 2027-10-20.
- Выплата на ноту: `1000 × min(0.2; max(BAP − 1; 0))`. BAP — среднее отношений финальных цен к начальным. Дополнительного возврата номинала нет.
- Условный купон: 0,01% годовых при BAP ≥ 1, с округлением до центов на ноту. ACT/365 по умолчанию — допущение, так как паспорт не уточняет DCF; доступен ручной DCF.
- Доходность учитывает введённые расходы; годовой пересчёт — сложный ACT/365 от даты покупки до плановой выплаты. Налоги, дефолт, корректировки и переносы календарных дат не моделируются.

Источник условий: `Паспорт_PCC_Call spreadl _clean.pdf`, стр. 1–2, 4–8. PDF не включён в публикацию. Дизайн и финансовые формулы перенесены из актуального локального калькулятора без изменений.

## Котировки

На статическом GitHub Pages локальный Python-загрузчик Nasdaq не применяется. Для котировок пользователь вводит собственный ключ Twelve Data. Запрашиваются точные тикеры на NYSE Arca (`ARCX`) в USD. Доступность и задержка зависят от тарифа. Все расчёты работают без ключа и авторизации.

Ключ отправляется только Twelve Data, не сохраняется в браузере и не включён в репозиторий. Котировки не заменяют официальные первоначальные цены и не меняют сценарий автоматически. Ошибки показаны пользователю; демонстрационные цены не выдаются за реальные.

## Проверка

Проверены ввод параметров, пересчёт, купонный барьер, предельная выплата, комиссии, целое число нот при бюджете, отрицательные сценарии, CSV и мобильный экран 390 px. Прямое подключение котировок проверено с имитированными ответами API и ошибками; для реальных котировок требуется действующий личный API-ключ.
