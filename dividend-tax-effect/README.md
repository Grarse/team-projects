# Дополнительный доход на отложенном НДФЛ

[Открыть калькулятор](https://grarse.github.io/team-projects/dividend-tax-effect/)

Дополнительный заработок на деньгах, которые при ежегодной выплате дивидендов ушли бы на НДФЛ. Два результата: заработок в компании и деньги владельцев после налогов.

Автономная HTML-страница без внешних библиотек. Параметры: прибыль и доходность по годам, срок 1–10 лет, 1–4 собственника с равными долями, налог компании. Настройки сохраняются только в браузере.

Модель БПИФ: налог с роста стоимости рассчитывается при продаже паёв в конце срока. Шкала НДФЛ 13–22% для дивидендов используется как сценарий предполагаемой реформы. Результат выделяет только доход на временно оставшихся суммах НДФЛ; это не сравнение с личным реинвестированием всех ежегодных дивидендов.
